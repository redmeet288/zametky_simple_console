Notes
Простое консольное приложение для управления текстовыми заметками с автосохранением в JSON.

Функционал
Создание заметок с заголовком и описанием

Просмотр всех заметок

Редактирование (текущий текст|новый текст)

Удаление заметок

Автосохранение в notes.json

интерфейс с нумерацией

Быстрый старт
Клонировать репозиторий, перейти в папку, запустить python notes.py
